# Configuration Reference

This distribution is configured through repository-local CLI state and optional process environment variables. It does not automatically load `.env` files.

Canonical commands on Windows:

```powershell
node .\dist\cli.js init
node .\dist\cli.js doctor
node .\dist\cli.js config get
node .\dist\cli.js config set publicBaseUrl 'https://<public-origin>'
node .\dist\cli.js config set publicBaseUrl null
```

Do not use `npx @waishnav/devspace` for this distribution.

## Persisted files

Default user state:

```text
~/.devspace/config.json
~/.devspace/auth.json
```

`auth.json` contains the Owner credential and must remain private.

`DEVSPACE_CONFIG_DIR` can relocate these files when intentionally configured.

## Local and remote operation

`publicBaseUrl` is optional.

- local-only: omit it or persist `null`;
- remote: set an HTTP/HTTPS origin without `/mcp`.

When no public URL is configured, DevSpace derives its MCP/OAuth base from the local bind address, normally `http://127.0.0.1:7676`.

Remote ingress is outside the DevSpace domain model. Cloudflare Tunnel is one possible reverse proxy, not a requirement.

## Core environment variables

| Variable | Default | Purpose |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | Local bind host. |
| `PORT` | `7676` | Local port. |
| `DEVSPACE_ALLOWED_ROOTS` | current working directory when unset | Comma-separated workspace roots. Prefer persisted explicit roots from `init`. |
| `DEVSPACE_PUBLIC_BASE_URL` | local bind origin | Optional remote public origin without `/mcp`. |
| `DEVSPACE_ALLOWED_HOSTS` | derived | Optional Host header allowlist override. |
| `DEVSPACE_CONFIG_DIR` | `~/.devspace` | Config/auth directory. |
| `DEVSPACE_STATE_DIR` | `~/.local/share/devspace` | SQLite state directory. |
| `DEVSPACE_WORKTREE_ROOT` | `~/.devspace/worktrees` | Managed Git worktrees. |

## Tool surface

This distribution uses the Codex-style tool surface by default:

```text
open_workspace
read
apply_patch
exec_command
write_stdin
```

There is no tool-mode setting in the supported deployment contract. Legacy `DEVSPACE_TOOL_MODE` / `DEVSPACE_MINIMAL_TOOLS` environment values are not used to select another surface.

`exec_command` runs non-PTY commands by default. Use `tty: true` only when a terminal is required. `write_stdin` polls or interacts with a running process session.

## Widgets

`DEVSPACE_WIDGETS` controls MCP Apps UI:

| Value | Behavior |
| --- | --- |
| `full` | Default. Attach supported tool UI. |
| `changes` | Expose the aggregate `show_changes` review flow. |
| `off` | Disable widget UI. |

## Skills

| Variable | Purpose |
| --- | --- |
| `DEVSPACE_SKILLS` | Set `0` to hide Skills; enabled by default. |
| `DEVSPACE_AGENT_DIR` | Defaults to `~/.codex`; its `skills` child is a global catalog. |
| `DEVSPACE_SKILL_PATHS` | Optional comma-separated additional Skill directories. |
| `DEVSPACE_SUBAGENTS` | Experimental Subagents; disabled by default. |

Default global Skill catalogs:

```text
~/.agents/skills
~/.codex/skills
```

Workspace-local catalog:

```text
<workspace>/.agents/skills
```

`~/.devspace/skills` is not used.

When Subagents are enabled, profiles are discovered from:

```text
~/.devspace/agents/*.md
<workspace>/.devspace/agents/*.md
```

Subagents are experimental. The current `subagent-delegation` workflow invokes `devspace agents ...`; a clean repository-only deployment should not assume that command is globally available unless the operator explicitly provides a CLI entry point. This limitation does not affect the default Subagents-off deployment.

## OAuth

| Variable | Default |
| --- | --- |
| `DEVSPACE_OAUTH_ACCESS_TOKEN_TTL_SECONDS` | `3600` |
| `DEVSPACE_OAUTH_REFRESH_TOKEN_TTL_SECONDS` | `2592000` |
| `DEVSPACE_OAUTH_SCOPES` | `devspace` |
| `DEVSPACE_OAUTH_ALLOWED_REDIRECT_HOSTS` | `chatgpt.com,localhost,127.0.0.1` |

`DEVSPACE_OAUTH_OWNER_TOKEN` may supply the Owner credential for env-driven deployments, but normal interactive setup should use the credential generated by `init`.

## Artifacts

`DEVSPACE_ARTIFACTS=1` enables native-file download only on supported platforms. The current secure native-file implementation is Linux-specific and is not registered on Windows. Do not enable it expecting Windows support.

`DEVSPACE_ARTIFACT_MAX_FILE_BYTES` defaults to `104857600` bytes.

## Logging and proxy trust

| Variable | Default |
| --- | --- |
| `DEVSPACE_LOG_LEVEL` | `info` |
| `DEVSPACE_LOG_FORMAT` | `json` |
| `DEVSPACE_LOG_REQUESTS` | `1` |
| `DEVSPACE_LOG_ASSETS` | `0` |
| `DEVSPACE_LOG_TOOL_CALLS` | `1` |
| `DEVSPACE_LOG_SHELL_COMMANDS` | `0` |
| `DEVSPACE_TRUST_PROXY` | `0` |

The repository Windows launchers set `DEVSPACE_TRUST_PROXY=1`; server code then trusts forwarded metadata only from loopback proxies. Local-only operators launching the CLI directly do not need proxy trust.

Enable shell command logging only when commands cannot contain sensitive values.

## Windows launcher override

`DEVSPACE_GIT_BASH` is consumed by the repository Windows launchers, not by core config parsing. Set it only when automatic Git Bash discovery selects the wrong executable or cannot find one.
